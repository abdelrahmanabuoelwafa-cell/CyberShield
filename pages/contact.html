Before you write

Frequently Asked Questions

Can I reuse the images from this website?

The edited images are part of an educational project. The layered PSD files are included in the project folder so the editing steps can be studied.

I clicked a suspicious link, what now?

Disconnect from the internet if you entered credentials, change that password immediately (and everywhere it was reused), enable 2FA, and run an antivirus scan.

Which tool did the team use for editing?

Adobe Photoshop. Each image keeps its original version and an edited version; techniques include crop, brightness/contrast, hue/saturation, levels, unsharp mask, gradient map, vignette, curves and color grading.
